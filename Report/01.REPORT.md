## 4. Mom Test 분석

### 4.1 표면 문제 (잘못된 정의 — 문제 정의에 쓰지 않음)

Mom Test에서 **문제 정의에 쓰면 안 되는** 문장들:

| # | 표면 문제 (솔루션 섞임) |
|---|-------------------------|
| 1 | 「ECB 구조로 4×4 마방진 검증·솔버 **프로그램을 만든다**」 |
| 2 | 「행·열·대각선 합을 자동으로 체크하는 **Validator 기능**을 만든다」 |
| 3 | 「GridUI·MissingFinder가 있는 **마방진 앱**을 만든다」 |

> 부분 마방진을 다 맞췄다고 **확신**했지만, 검사해야 할 줄·대각선 중 **하나(부대각선)를 빠뜨린 채** 행·열만 반복 검증했고, 그 **잘못된 “완료” 판정** 위에서 **약 35분**을 허비한 뒤에야 누락을 알게 되었다.

## 7. Mom Test 워크북 (최종)

### 페르소나 *(가상)*
프로그래밍 수업에서 4×4 부분 마방진(빈칸 2개) 과제를 받은 학생.

### 인터뷰 답변 (과거 사실)
- 「지난주 목요일 실습 … 빈칸 두 개에 1~16 … 행·열·대각선 합 34 … ECB로 클래스 나눠서 코드 …」
- 「빈칸 두 개에 11이랑 6 … 행·열만 … **35분** … ECB 쪽은 손도 못 댔어.」
- 「**부대각선**은 아예 안 더했어 … 행 3번째랑 열 2번째만 반복 …」

### 표면 문제 (금지 — 솔루션 섞인 문장)
- 「ECB 구조로 4×4 마방진 프로그램을 만든다」

### 진짜 문제 (한 문장)
